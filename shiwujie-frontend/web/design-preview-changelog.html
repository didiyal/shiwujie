v3.0.0 2026-07 Major

官网全新上线 & 架构升级 🎉

视无界正式推出品牌官网；后端反思微服务过度设计，完成单体化改造（7 模块 → 2 模块），全面加固安全体系并补齐单元测试；App 修复多项稳定性与安全问题。

🖥️ 官网 & Web 管理端
  • 新增品牌官网首页上线，Apple 风格设计系统
  • 新增官网导航：产品介绍、更新日志、GitHub、管理端入口
  • 新增App 软件下载功能，支持 Android APK 直接下载
  • 优化管理端整体 UI 升级：暗色侧栏 + 毛玻璃顶栏，统一圆角/间距/字体体系
⚙️ 后端：单体化改造
  • 优化模块合并 7→2（model 契约层 + bootstrap 唯一应用），删除 gateway 模块
  • 优化去 Spring Cloud / Nacos / Dubbo，统一 Spring Boot 3.4.5 / Java 21
  • 优化4 分库合并为单库 shiwujie，跨库写操作升级为单事务保证一致性
  • 优化合并 4 份重复 LoginCheckInterceptor / WebConfig 为公共各 1 份
  • 优化对外 HTTP 路径 / WS 12 信令 / 状态码 / 返回字段零变更，前端无需改动
🔒 安全加固
  • 优化密码存储 MD5 → BCrypt（cost=10，盐内嵌），存量 MD5 首次登录时懒升级
  • 修复恢复社区求助帖/活动/管理员增删改权限检查，此前任意登录用户可操作
  • 修复改密接口补 ownership 校验 + 原密码必填校验，修复账户接管漏洞
  • 修复修正 deleteCommunityManager 忽略请求体、恒删调用者自己的 bug
🤖 AI 模块
  • 优化文本模型 qwen3-max → qwen3.6-flash，路径改 OpenAI 兼容直连止血
  • 新增AI 集成冒烟测试，文本/图像模型回归可用性自动验证
📱 App 修复（P0 + 批次 A/B）
  • 修复WebSocket 心跳实际间隔 2h → 30s，长连接不再被 NAT 静默掐断
  • 修复视频通话监听器泄漏：onDestroy 误调 remove(null) 致 Activity 销毁后仍收回调
  • 修复紧急求助「无法再次求助」死锁：新增 60s 家属无响应超时自动复位
  • 修复AI 页面 WebSocket 断线不重连：attemptReconnect 只打日志从不调 connect
  • 修复紧急求助超时在通话进行中误触发——WebSocketManager 补发消息处理
  • 修复WS 重连 5 次用尽后永久失活：改为快速窗口（3s）+ 慢速持续重试（60s）
  • 修复VideoCallManager 回调跑在子线程，切回主线程防 UI 崩溃
